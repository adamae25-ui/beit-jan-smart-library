# Beit Jan Smart Library 📖

מערכת ניהול ממוחשבת לספריית תיכון בית ג'ן — מימוש מלא של מסמך האפיון (קוד עבודה 20262P48).

**Mockup:** https://adamae25-ui.github.io/beit-jan-library/

## סטאק טכנולוגי

| רכיב | טכנולוגיה |
|---|---|
| Backend | Node.js + Express (REST API) |
| Frontend | React 18 + Vite |
| Database | MySQL 8 |
| Auth | JWT + bcrypt |

## מבנה הפרויקט

```
beit-jan-library/
├── server/          # Backend API
│   ├── sql/
│   │   ├── schema.sql   # סכמת מסד הנתונים המלאה
│   │   └── seed.sql     # נתוני פיתוח (תואמים למוקאפ)
│   └── src/
│       ├── index.js             # נקודת כניסה
│       ├── db.js                # חיבור MySQL (pool)
│       ├── middleware/auth.js   # JWT + הרשאות תפקיד
│       └── routes/auth.routes.js
└── client/          # Frontend React
    └── src/
        ├── api.js               # שכבת קריאות לשרת
        ├── auth/AuthContext.jsx # ניהול session
        ├── components/Layout.jsx# מעטפת + סרגל צד לפי תפקיד
        └── pages/               # Login, Dashboard
```

## התקנה והרצה (פיתוח מקומי)

### 1. מסד נתונים

ודאו ש-MySQL 8 מותקן ורץ, ואז:

```bash
mysql --default-character-set=utf8mb4 -u root -p < server/sql/schema.sql
mysql --default-character-set=utf8mb4 -u root -p < server/sql/seed.sql
```

> חשוב: הדגל `--default-character-set=utf8mb4` הכרחי כדי שהטקסט העברי בנתוני ה-seed ייטען תקין.

### 2. Backend

```bash
cd server
cp .env.example .env      # ערכו את פרטי החיבור ל-MySQL
npm install
npm run dev               # http://localhost:4000
```

בדיקת תקינות: http://localhost:4000/api/health

### 3. Frontend

```bash
cd client
npm install
npm run dev               # http://localhost:5173
```

ה-Vite proxy מפנה אוטומטית קריאות `/api` לשרת בפורט 4000.

- [x] **שלב 4:** מנוע התראות מלא — תבניות בעברית, ארכיטקטורת ספקים (console לפיתוח / Twilio / SendGrid דרך REST ללא תלויות), worker כל דקה, מתזמן תזכורות והתראות איחור (אידמפוטנטי), יומן התראות לספרנית; אינטגרציית Google Books API למילוי אוטומטי מ-ISBN
- [x] **שלב 5:** דוחות (השאלות לפי חודש/ז'אנר/כיתה, ספרים מבוקשים, שיעור איחורים, חובות) לספרנית והנהלה, מסך הגדרות מערכת (מכסות, ימי השאלה לפי ז'אנר, תוקף שריון, ערוץ התראות), מסך ניהול תלמידים עם הסדרת חובות (הנמקה חובה)

- [x] **שלב 6 — העוזר החכם (AI Agent):** סוכן AI מבוסס Claude API עם Tool Use — עונה בעברית, שולף נתונים אמיתיים מהמערכת (חיפוש ספרים, ההשאלות/שריונים/חובות של המשתמש, נתוני ספרייה והגדרות) לפי הרשאות התפקיד, בווידג'ט צ'אט צף בכל המסכים

## הפעלת העוזר החכם

1. הנפיקו מפתח API ב-https://console.anthropic.com
2. הוסיפו ל-`server/.env`:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. הפעילו מחדש את השרת. בלי מפתח - המערכת עובדת רגיל והעוזר מציג הודעת הגדרה.

העוזר משתמש במודל `claude-haiku-4-5` (מהיר וזול; ניתן לשנות עם `ASSISTANT_MODEL`). הוא מקבל כלים לפי תפקיד המשתמש: תלמיד יכול לשאול על הספרים/השאלות/חובות שלו; ספרנית והנהלה - על נתוני הספרייה. הסוכן שולף נתונים אמיתיים מ-MySQL ואינו ממציא מידע.

## הערות אבטחה

- סיסמאות נשמרות כ-bcrypt hash בלבד
- JWT עם תפוגה (ברירת מחדל 8 שעות)
- הודעת שגיאה אחידה בכניסה (מניעת user enumeration)
- אין להעלות את קובץ `.env` ל-Git
